Acerca de nosotros

Bienvenido a nuestra página web. Este proyecto ha sido creado para practicar el desarrollo de páginas web y el trabajo colaborativo mediante GitHub.

En esta página podrás encontrar información sobre nuestro proyecto, conocer sus diferentes secciones y ponerte en contacto con nosotros.

Sobre el proyecto

Esta página web forma parte de un proyecto de aprendizaje en el que trabajamos con HTML, CSS, JavaScript y GitHub.

Nuestro objetivo es mejorar progresivamente el diseño y las funcionalidades de la página mediante el trabajo colaborativo y el uso de ramas y Pull Requests.

¿Qué puedes encontrar aquí?

  • Información sobre nuestro proyecto.
  • Un buscador para practicar funcionalidades web.
  • Una página de contacto.
  • Un sistema de inicio y cierre de sesión.
  • Enlaces a nuestras redes sociales.
